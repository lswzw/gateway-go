# Gateway-Go 性能测试报告

> 数据来源：2026-10，Docker 容器隔离 + `hey`。历史一轮数据见[附录 A](#附录-a历史数据2025-06jmeter--2c2g)。

## 1. 测试环境

| 项目 | 配置 |
|---|---|
| 宿主机 | 12 vCPU / 31 GiB，Linux，内核默认网络参数 |
| 网关容器 | 4 vCPU（`--cpuset-cpus 0-3`）、2 GiB、`alpine:3.22` + 静态编译二进制 |
| 后端容器 | 4 vCPU（`--cpuset-cpus 4-7`）、2 GiB、`nginx:stable-alpine`（`access_log off`，`return 200 "backend-ok\n"`） |
| 压测容器 | 4 vCPU（`--cpuset-cpus 8-11`）、4 GiB、`hey v0.1.4` |
| 网络 | 自定义 bridge（172.31.99.0/24），容器间 RTT < 1 ms |
| 网关版本 | `1.0.0`，`go1.26.10`，`CGO_ENABLED=0 -trimpath` |
| 网关配置 | `server.mode: release`、`log.level: error`、`admin.listen: 0.0.0.0:9090` |

## 2. 测试方法与口径

- 命令：`hey -z 25s -c <并发>`，HTTP keep-alive 开启。
- 每轮先预热 5 s（结果丢弃），再计时 25 s。
- 每个用例前重启网关与后端容器，清空网络命名空间内残留的 `TIME_WAIT` 与限流令牌桶。
- 延迟取 p50 / p90 / p99。
- 计数交叉校验：`hey` 的 RPS 与网关 `/metrics` 的 `gateway_requests_total` 增量一致（180 s 长稳：`5,011,490 / 180 s = 27.8k RPS` vs `hey 27,841 RPS`，偏差 < 0.2%）。

## 3. 被测路径

| 标记 | 请求地址 | 语义 | 插件链 |
|---|---|---|---|
| `direct` | `http://后端:80/` | 绕过网关直连 nginx | — |
| `self` | `http://网关:8080/` | 网关内部响应（`internal://default`） | 无 |
| `noplug` | `http://网关:8080/noplug` | 纯反向代理 | 无 |
| `plug` | `http://网关:8080/plug` | 反向代理 + 插件链 | `rate_limit` → `circuit_breaker` → `cors` |

被测路由均 `retries: 0`；`plug` 的限流阈值设为 1e6 rps，仅测量令牌桶路径开销，不产生 429。
